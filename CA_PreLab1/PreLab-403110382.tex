	\section{Questions}
	\begin{enumerate}
		\item 
		An ALU (Arithmetic Logic Unit) is a core component of the CPU that performs arithmetic and logical operations on binary data. Arithmetic operations such as, addition, subtraction and increment/decrement. Logical operations such as, AND, OR, NOT, XOR and bit shifting. 
		\item 
		\var{S0-S3} and \var{M} is for the function select. 16 different operation is available.
		Due to the "AC characteristic" table in the data sheet, the longest delay is for $\overline{A \oplus B}$.
		\item 
			In puts are given to ALU through \var{A} and \var{B} input pins. With the function select pins we chose XNOR($S_0 = S_3=M = H\quad S_1 = S_2 = L$). 
			
		\item 
			Due to the AT28C16 data sheet, it has 16k memory. Maximum address to output delay is 150 ns.
		\item 
		By connecting the synchronous counter to addresses(first 4) we can have first 16 memory locations.
	\end{enumerate}
