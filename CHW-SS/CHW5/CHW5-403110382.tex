		We encountered an anomaly. It seems like the 200Hz sampling rate has lower error than 500Hz. This effect is normal, though it feels incredibly counterintuitive. Theoretically both frequencies are able to construct exact signal. By cutting off the signal at 0 and 0.1 seconds, we make artificial sharp edges that troubles sinc-interpolation. The sinc interpolation tries to reconstruct these nonexistent sharp edges, which causes extreme oscillation near the boundaries. If you look at the boundaries you can see this effect. 
		
		At 500 Hz, the interpolation has a Nyquist bandwidth of 250 Hz. Because the bandwidth is so wide, the math attempts to accurately trace that artificial sharp drop-off at the edges. This generates high-amplitude, high-frequency (up to 250 Hz) Gibbs ringing that bleeds into your time window.
		
		At 200 Hz, the Nyquist bandwidth is exactly 100 Hz. The interpolation is mathematically physically incapable of generating frequencies above 100 Hz. Because your true signal is 90 Hz, this tight bandwidth perfectly preserves your original signal while acting as a strict low-pass filter that blocks the high-frequency truncation artifacts.
	\subsubsection{Code}
	Instead of summation over \var{n} and \var{t}, we use the MATLAB built-in matrix multiplication that execute much faster than a simple loop.
	\begin{lstlisting}
Fs = [150 , 200, 500];
Ts = 1./Fs;

t1 = 0:Ts(1):0.1;
t2 = 0:Ts(2):0.1;
t3 = 0:Ts(3):0.1;

t = linspace(0,0.1, 50000);
x = func(t);

%Fs = 150Hz
[Ts_grid, T_grid] = ndgrid(t , t1);
x1 = func(t1);
x_r1 = sinc((Ts_grid-T_grid)./Ts(1))* x1(:);
	\end{lstlisting}

	\subsection{Code}
	We use a built-in MATLAB function called \var{interpolate} for the ZOH reconstruction. 
	\begin{lstlisting}
Fs = 100;                 
Ts = 1/Fs;                
t = 0:0.0001:0.5;         
t_n = 0:Ts:0.5;           

x_t = sin(2*pi*10*t) + 0.5*sin(2*pi*35*t);
x_n = sin(2*pi*10*t_n) + 0.5*sin(2*pi*35*t_n);

x_zoh = interp1(t_n, x_n, t, 'previous'); 

[Ts_grid, T_grid] = ndgrid(t, t_n);
x_sinc = sinc((Ts_grid - T_grid) / Ts) * x_n(:);

error_zoh = mean((x_t - x_zoh).^2);
error_sinc = mean((x_t - x_sinc').^2);

	\end{lstlisting}
