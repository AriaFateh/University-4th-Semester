	\section{DFT Algorithm Implementation}
	\subsection{Implementation}
	\subsubsection{Loop}
	It is implemented in \var{myDFTLoop} function. It is directly obtained by the following formula,
	\begin{equation}
		X[k] = \sum_{n =0}^{N-1} x[n] \, e^{-j \frac{2\pi}{N} k n}
	\end{equation}
	Which $N$ is the array's size.
	
	\begin{lstlisting}
function X = myDFTLoop(x)
	N = length(x);
	X = zeros(N,1);
	for k=1:N
		for i = 0:N-1
			X(k) = X(k) + x(i+1).*exp(-1j.*2*pi./N.*(k-1).*i);
		end
	end
end
	\end{lstlisting}
		
\subsubsection{Matrix}
First we construct a matrix (\var{W}) which DFT array of \var{x} is calculated by $W x$. 
\begin{lstlisting}
function X = myDFTMatrix(x)
	N = length(x);
	X = zeros(N , 1);
	n = 0:N-1;
	W = exp(-1j * 2 *pi / N *(n'*n));
	X = W * x(:);
end
\end{lstlisting}
\subsection{Norm Difference}
For a random sequence of numbers with size 256, we calculate DFT with two mentioned functions. Norm-2 of difference of the implemented and built-in function shows how accurate our calculations is.
The order of magnitude of the error is $10^{-12}$. 
\subsection{Time-Complexity}
The figure \eqref{DFT_Comparison} shows, FFT algorithm is meaningfully fast, two and four order of magnitude faster than the matrix and loop implementation respectively. In the figure \eqref{DFT_Comparison_loglog} the performance of each method is more clear and readable. The time-complexity of loop and matrix are both $\mathcal{O}(N^2)$ but FFT is $\mathcal{O}(N \log{N})$.

	\subsection{Spectral Leakage}
	The DFT assumes that the finite sequence it analyzes is one period of an infinitely periodic signal. Your observation window is 	$T=0.2$ seconds. For $f_1=100 \, \text{Hz}$, the window contains exactly 20 cycles, so it aligns perfectly. However, for $f_2 = 123.5 \, \text{Hz}$, the window contains exactly 24.7 cycles. Because this is not an integer number of cycles, wrapping the end of the signal back to the beginning creates an abrupt, artificial discontinuity. It is shown in figure \eqref{Leakage}.
	\begin{figure}
		\centering
		\includegraphics[width = 0.8\textwidth]{2-2-d.jpg}
		\caption{Sloped skirt due to the uncompleted cycles.}
		\label{Leakage}
	\end{figure}
	\subsection{Hann and Hamming Window}
